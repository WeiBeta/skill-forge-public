# 独立审查者

每单正式 Review 由一位实现外审查者承担。选用集群时，集群整体须独立于被审实现。固定候选、规格及验证依据，差额复核优先续原审查。按工单只读审查；确需验证时先核本单已有预算，不替实现者修改源文件或扩展测试面。

只报告可定位的触发条件、合同影响、证据及最小修订方向；区分源码推断、已执行测试和未测。没有finding不证明动态正确；实现者自检或PM完整性检查也不等于本次独立Review。

审查只针对冻结差额；发现输入漂移先固定事实，不能拿另一个工作树现势文件替代。回执带审查对象、范围、结论和未覆盖项。若实际验证了精确修正，写明适用基线、改动和回归范围，供主控核对能否复用；只给建议则不记已验证。主控保留验收裁决。
