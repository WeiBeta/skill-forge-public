# 工程派工与回收

先定位项目既有管理入口、唯一写入者、目标、暂停和已授权范围。用稳定任务ID连接现势与固定工单，不恢复全部历史。技能指导流程，不授权创建独立聊天、切换模型、外发或新增运行次数。

## 分工与切片

主控负责工程取舍、路由、任务边界、核收与权威记录；协调者负责冻结的委派、事件回收与结果汇总；执行者在写集内交付。没有协调层时可由主控直接委派，不为套结构增加岗位。正式独立Review使用实现外的新实例，不能用内部辅助代理意见替代。

按本次不变量耦合、失败影响和可验证性选择角色，再按项目真实可用路由选模型。已收敛的实现不因主链复杂继承高档；不以配额、行数或固定比例派工。模型/档位逐单显式绑定，核自定义角色固定值是否冲突，避免继承协调者设置。

默认交完整工作包：实现、针对性自测、结果采集和证据收尾由同一执行者负责，可在包内划出审查或运行阶段。只在需要独立性、存在实际冲突、权限另有边界或部分结果可独立验收时拆分。主控负责工程取舍和验收，执行者在冻结边界内决定普通实现、测试辅助与采集修正。独立聊天创建、内部子代理及正式审查分别核适用授权；不把职责说明当工具授权。

## 派前核依赖

派工、核收或阻断改变下一步时，合并判断固定输入、真实依赖与汇合条件。分别核任务实例、实际执行根与 Git 状态、共享输出/缓存/进程和独占资源；其中一项隔离不能替其他项作证。获准且可隔离的工作直接推进，只有冲突部分需要串行。

固定目标、验收与业务语义，明确必要输入、执行根、允许写入范围、路由和回执目标；按风险补充精确叶集、预算与停止线，见[工单与回执](references/work-orders.md)。区分用户硬边界、工具许可和管理检查点；只为真实权限、影响或预算差额请示。

## 按风险验证

机械且行为不变的修正核差异及针对性证据。行为、业务语义或高影响变更依项目规则做适用测试和正式独立审查。先做获准、前置齐备且能回答问题的最窄开发验证；冻结工单有先审要求时照办。正式验收另绑实际候选、范围与原始结果，开发反馈不能代替验收。

优先复用稳定入口。只改候选、输出位置或测试选择等绑定时，核实际参数、产出和范围；控制或验收语义变化按风险补验证与审查。只有独立审查已验证精确修正，且实际基线、实施差额、组合影响与必要回归仍在覆盖内，才复用该审查结论；建议或换提交号均不能决定是否重审。超出覆盖只补受影响部分，汇合时仍核实际组合。

## 等待与恢复

先分清接收关系：主控只等独立PM时保存断点，按已验证的实质消息机制结束回合；直接父会话（包括获准直派的主控）尚须回收原生子任务时保持接收回合，用实际可用事件或直接等待消费结果，不套用前者的结束规则。首次适配或发生误用、工具差异时读[运行适配](references/runtime.md)。不能把await挂起、外层让出或timeout当作父回合结束，也不假定子事件能重启已结束父回合。

无适用事件等待时，只沿项目已明确授权的有界适配：绑定具体子任务、实际工具、等待/必要精确确认的累计预算与停止线，按当前schema和上层限制选择低频调用。无获准适配则留人工续接入口。

所有等待路径共用停止线：超时不作终态；适用预算耗尽或无合法等待区间，就保存未终态、已用预算和恢复入口，同时停止追加等待/确认，不自动续额、重派或取消子业务。仅剩子结果本身不是提前结束的理由；停止线触发时仍应交接收口。PM逐单核最低完整性并实质回主控；主控直派时按自身职责核收，不制造向自己回执的步骤。

正常等待不报故障，不用列表轮询、短等待外层循环或空ACK模拟完成通知。每单及约定须回执的阶段在完成、失败、阻断或需裁决时及时提交一次实质结果；只有当下已齐或成员已冻结的批次才合并；新任务不延长旧批次。接收方用任务、阶段、候选与终态去重，重复消息不重新派工或执行。

失败先判层次与实际副作用：能核回结果就补采，确定性错误先局部纠正；只有瞬态原因且可证实未执行或可安全重复时才考虑原样重试。通信、服务、入口尝试与业务启动按各自约定累计，不能互借。权限拒绝即停该操作，不换命令、模型或通道绕过。Unknown 只阻断依赖它的动作；业务是否启动不明时不能重放。

## 核收与续接

执行者交候选、实际验证与资源状态。协调者默认只核任务/实例对应、冻结目标、字段完整、异常、预算与关闭；额外工程核验由工单指定，不重复逐叶审计或业务Review。Git锁若确需检查，用Git解析实际git-dir/index路径，不把linked worktree的.git指针当目录。

回执中的提交、计数和时间直接取可靠字段；无证据填Unknown。分清执行者报告、协调者实查、主控验收；读取摘要/manifest不等于重算原始字节。越写集、禁止动作或未授权删除明确列范围/协议偏差，不能淡化为保留项；发生删除不能总括未清理。执行错误与转述错误分别归因，同事件不重复计数。

主控按风险核固定对象和关键证据后裁决；事实留在原记录，CURRENT 只更新受影响的现势、责任和下一依赖。依赖后续等必要核收与落盘。受理不等于执行，阶段完成不等于父目标完成；只剩独立协调回执时按已核实的续接机制收口。

子任务终态、资源释放、载体关闭和资产可删除分别判断。无公开close接口就保留Unknown，不能interrupt/强杀代证。清理另核授权与保全，最终交代完成范围、失败未测及下一入口。
