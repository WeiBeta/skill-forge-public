# 工单与回执的最小信息

仅在需要编制或检查结构时读取；字段随任务风险裁剪，不让普通小改强制建多层工单。

## 工单

列任务ID、目标与验收、必要固定对象、实际执行根和允许写入范围、角色/路由及回执目标。只在实际需要时列精确文件、字节哈希、适用授权与停止线、共享资源、汇合条件和累计预算。预算按约定区分入口尝试与真实启动，不猜默认次数；交付报实际变更路径。

示例：T-12 在隔离树 A 修订解析器，可编辑该模块及测试，用现成本地夹具找最窄反例，提交候选和证据；语义变更在候选固定后交未参与实现者审查。T-13 在另一树只读检查独立文档，两单分别回执。若另有字节接收合同，再为该合同列固定文件及哈希。

## 回执

- 任务/实例与候选提交，或明确无写入。
- 实际结果、失败/范围偏差、未验证项。
- 已消费预算和副作用状态。
- 资源与close证据，未知分别保留。
- 事实来源：执行者报告 / 协调者实查 / 主控验收。
- 固定证据指针、需裁决项和下一依赖。

以任务、阶段、候选与终态识别重复回执；引用事实所在记录。消息受理、送达、执行和核收分别判断。保留旧失败及真实预算消费；暂停回执要留下现场和续接条件。
