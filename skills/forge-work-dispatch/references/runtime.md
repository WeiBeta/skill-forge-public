# 按能力适配宿主

首次适配、接口变化、冷启动误用或实际故障时读取。接收关系、暂停与累计预算以 PM 的[接收合同](../../forge-pm-management/references/reception.md)为准；本页用于核对执行与证据能力。

| 能力 | 核实什么 |
| --- | --- |
| 创建/路由 | 原生子代理与独立聊天分别处理；显式参数、受理、自报、服务身份分列 |
| 隔离 | 分别核实例身份、实际工作目录与 Git 根、index/ref、共享缓存/输出/进程及独占工具；创建成功不等于已分配树 |
| 结果与消息 | 任务标识、终态/结果读取、实际通知目标与生命周期证据分别核对 |
| 权限 | 当前实际限制；父配置和角色说明不能代证子执行权限 |
| 关闭 | completed、公开 close、资源释放分别有证据；缺接口不猜替代命令 |
| 恢复 | 本项目预算、幂等性、副作用；通信/服务/业务次数分开 |

原生 Codex 与 Codex＋OpenCodex 是不同适配路线。按实际宿主和工具组合核 V1/V2 能力，不互套参数和恢复动作。模型家族不是协议证据。换宿主或实例先保存安全断点、已用预算和资源归属，不能假定继承权限或进程。绑定条件不变时复用证据，只重核实际变化。

工具外层反复续等可能触发父模型请求；零空转须用真实请求记录验证。模型总用量不等于协调浪费，缓存输入不得重复计入。普通任务不为填 Unknown 重跑性能或权限探针。
