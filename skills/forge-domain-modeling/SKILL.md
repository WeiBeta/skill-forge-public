# 领域与工程语义

只在本次判断涉及术语歧义时查对应权威来源，不每轮通读治理，不为每个词发问卷。先用具体边界场景明确对象、允许动作和结果；无法从合同决定时提出最小裁定问题。

源码仓库、工作树、安装实例、宿主原生 Project 与本次执行授权是不同身份。版本名相同不证明字节相同；会话标题、路径名或共享 Git 对象库不证明真实运行目录或系统隔离。

区分控制完成、进程退出、Worker/业务产物、核验器结论和管理 Accepted；计量资格、样本覆盖与业务判定也各有对象。缺某层证据不自动否定其它独立成立的层，不由 exit 0 或报告格式齐全推导全部通过。

定义保存稳定含义，运行值与授权回到既有台账和工单。客户既有领域真源优先，不自动建 GLOSSARY、改数据库或移植其它项目词表。只有难逆、未来难理解且存在真实取舍时，在既有决策位置记录简短 ADR 与替代关系。

读[边界案例](references/cases.md)处理分层状态或跨环境推断；来源见[归属](references/attribution.md)。
