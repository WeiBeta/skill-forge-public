# 边界场景

- 控制采集完成、Worker Blocked：采集层成功，不等于业务交付完整。
- 原生宿主失败、某局部产物有独立绑定的有效验证：保留失败，同时限定接受有证据的局部事实，不升为整体成功，也不全盘否定。
- 正对照有效、实际首样本失败：计量器在该环境具备部分资格，不代表正式性能样本或另一个环境通过。
- 候选生成、客户未接纳：属于交付准备，不是部署；文件安装、宿主发现、人工读取、实际应用、效果验证也不互相替代。
- 一次迁移完成：证明指定会话/文件平面的变化，不自动证明缓存兼容、运行资格或旧进程全部退出。

这些场景帮助核对现有合同，不能创建新状态机、统一客户业务枚举或扩大授权。
